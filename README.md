# Marker Hunter website

Public site for the Marker Hunter app, hosted free on GitHub Pages.

- `index.html`: home page
- `support.html`: help and contact (Apple requires a support URL)
- `privacy.html`: privacy policy (Apple requires one for TestFlight and the App Store)
- `styles.css`: shared look, matching the app

To edit: change the files, then commit and push in GitHub Desktop. The site updates within a minute or two.
